# Working in this project (for AI agents & humans)

This project was generated by **Sconix Research OS**. Every project has the
same shape, so follow these conventions exactly.

## Question

How do llms inference engins work?

## The only verbs

`task setup | run [-- expNNN] | exp -- <name> | compare | report | lint | test`

Never invent new workflows. If something is missing, add it as a `task`.

## Adding an experiment

1. `task exp -- short-name` → creates `experiments/expNNN_short-name/` from `experiments/_template/`.
2. Edit `experiments/expNNN_short-name/config.yaml` — only the keys that differ from `configs/default.yaml`.
3. Edit `experiments/expNNN_short-name/run.py` — the work. Keep the `with Run(...)` wrapper.
4. `task run -- expNNN_short-name`, then `task compare`.
5. Fill in `hypothesis.md` (predict before running) and `conclusion` after.

## Rules

- **Reproducibility is not optional.** All real work goes inside `with Run(EXP, config=cfg) as run:`. Use `run.log(step=, ...)` for curves and `run.summary(...)` for headline numbers. Do not write ad-hoc files outside `run.dir`.
- **Config, not constants.** New knob → add to `configs/default.yaml`, read via `load_config`. No magic numbers in `run.py`.
- **Promote shared code.** Logic used by 2+ experiments moves into `src/vllm_explore/`. Experiment folders stay thin.
- **`results/` is disposable** — it's git-ignored and rebuildable from code + config. Never commit it. Same for `data/` and `models/`.
- **Green before commit.** `task lint` must pass (ruff format + check + pytest).
- **Small commits**, one experiment or one `src/` change each.
- **`task run` auto-commits** any dirty working tree before running, so every `results/.../env.json` records a clean git sha instead of a diff. You don't need to remember to commit before running — but keep edits focused (see above) since the auto-commit message is generic (`auto-snapshot before run: <timestamp>`).

## sconixlib API (already installed, editable)

```python
from sconixlib import Run, load_config, set_seed, get_device, gpu_info, load_runs
```

- `load_config(*yaml_paths, **overrides)` — layered merge, kwargs win.
- `set_seed(seed, deterministic=False)` — python + numpy + torch.
- `get_device()` — cuda if available, with TF32/bf16 matmul enabled (5090).
- `Run(name, config=..., tags=[...])` — context manager; writes `results/<stamp>__<name>__<sha>/`.
- `load_runs("results/*")` — every run's summary as a DataFrame.

To improve the engine itself, edit `/home/sconix/research/os/sconixlib` — changes apply to every project immediately.
